# 未来智慧云图书管理系统 (Enterprise Library System 完全体)

这是一个企业级、工业化设计的全栈图书管理系统，遵循 **Google Material Design 3 (M3)** 现代设计规范，采用前后端分离架构，通过 **Bocker** 与 **Systemd** 实现全自动化容器镜像构建与服务治理。

---

## 一、 系统技术架构

### 1. 后端技术栈 (Backend)
- **FastAPI 0.141**：高性能异步 ASGI Web 框架，集成 Swagger / OpenAPI 接口文档
- **SQLAlchemy 2.0 ORM**：11 张核心业务模型，完整外键级联与索引支持
- **SQLite**：零配置单文件数据库（`backend/library.db`），可通过 `DATABASE_URL` 环境变量切换其他数据库
- **JWT + RBAC**：基于角色细粒度权限控制（Admin / Librarian / Reader）
- **Uvicorn**：高并发异步服务容器

### 2. 前端技术栈 (Frontend)
- **Vue 3.5 (Composition API)**：现代响应式单页面框架
- **Vuetify 3 (Material Design 3)**：官方 M3 设计系统，包含深色/浅色主题、动态 Elevation 与 Tonal 配色
- **Pinia**：全局响应式状态中心
- **Vue Router 4**：支持 RBAC 路由守卫与动态面包屑
- **SVG 响应式图表**：无外部臃肿依赖的 15 天实时走势波形图

### 3. 数据库与运行环境 (Database & Infrastructure)
- **SQLite**：本地与容器统一使用的单文件数据库，建表与种子数据由 `backend/init_db.py` 负责
- **Nginx**：高性能反向代理与静态资源缓存服务器（容器部署）
- **Systemd**：容器内全生命周期服务托管 (`library-api.service`, `nginx.service`)
- **Bocker (Incusfile v2)**：基于 Incus 的多阶段容器构建器

## 二、 核心功能矩阵 (完全体)

### 1. 权限与账户体系 (RBAC)
- **系统管理员 (Admin)**：全权配置、借阅流通规则设定、馆内公告发布、全系统敏感操作审计日志。
- **图书管理员 (Librarian)**：智慧借还服务台扫码连借、还书清算、图书采编编目、读者发卡开户与状态挂失冻结。
- **普通读者 (Reader)**：书目分面搜索检索、在线自主续借、图书无在架时排队预约、个人中心电子借书证展示。

### 2. 智慧借还服务台 (Circulation Desk)
- **扫码连借 (Fast Borrow)**：支持输入/扫描读者卡号，实时核验借阅额度、冻结状态与历史未缴罚金；支持扫枪连续扫描单册条码。
- **快捷还书 (Fast Return)**：扫描单册条码一键核销，自动释放在架库存；若逾期自动核算滞纳金并弹出前台收款/特批减免处理。
- **延期续借 (Renew)**：支持读者自助或前台代办续借，内置最大续借次数上限与逾期阻断防范。

### 3. 图书编目与单册追踪 (Inventory & Copies)
- **一书多册条形码追踪**：每本物理实体书均拥有唯一条码编号（如 `BK-2026-0101`），状态实时联动（在架、借出、预约保留、维修、遗失）。
- **双模展示**：Card 网格卡片与 Data Table 表格双视图一键切换。
- **分面高级检索**：支持书名、作者、ISBN、分类、书架位置、仅看有在架余量多重组合过滤。
- **批量导出**：支持全馆书目一键导出为标准 CSV 数据报表。

### 4. 财务罚金与预约排队
- **逾期滞纳金中心**：按日阶梯费率核算欠款账单，支持前台窗口收款与政策关怀特批减免。
- **预约排队队列**：热门图书借空时读者可登记排队，当有读者归还时系统优先锁定并推送通知。

### 5. 流通大数据统计看板
- 30 天借还走势波形面积图、全馆热门图书 TOP 榜单、分类藏书柱形占比分析。

## 四、 运行指南

### 1. 本地一键运行（Windows）
在项目根目录双击 `run.cmd`（或在终端执行 `.\run.cmd`）即可自动完成：创建 `.venv` 虚拟环境 → 安装后端依赖 → 安装前端依赖 → 编译前端 → 初始化 SQLite → 启动服务并打开浏览器。

- 所有依赖只落在项目内 `.venv\` 与 `frontend\node_modules\`，不会改动系统 Python 与全局 npm 环境
- 访问地址：`http://127.0.0.1:8000` （前端静态资源与 API 同端口，API 文档位于 `/docs`）
- 数据库文件：`backend\library.db`，删除该文件后再次运行会重新写入演示种子数据

### 2. 使用 Bocker 构建容器镜像
在项目根目录运行：
```bash
bocker image build --name library-management ./Incusfile
```

### 3. 启动容器
```bash
bocker image run library-management --name library-app
```

### 4. 访问系统
- **Web 门户**: `http://<容器IP>/` (默认端口 80)
- **API 文档 (Swagger)**: `http://<容器IP>:8000/docs`
